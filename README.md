# 🅿️ Parking Garage Management System

A Python-based parking garage management system developed as an academic project.

## 📌 About the Project

This project simulates the management of a parking garage, including user authentication, vehicle entry and exit, parking spot management, ticket generation, parking history, and revenue calculation.

The system was developed to practice programming fundamentals, data structures, functions, input validation, file handling, and basic software organization.

This project was developed using Python and GitHub.

## 🚀 Features

- User registration and login
- Administrator and regular user accounts
- Parking spot management
- Vehicle entry and exit
- Automatic ticket generation
- Different rates for cars and motorcycles
- Parking history
- Revenue calculation
- License plate validation
- Data persistence using text files

## 🛠️ Technologies & Concepts

- Python
- Regular Expressions
- File Handling
- Data Structures
- Functions
- Input Validation
- Date and Time Handling
